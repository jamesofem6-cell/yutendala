# Yutendala Buyer App

This repository replaces the former Epla project with the first Yutendala buyer-app package.

## Package
- `Yutendala_Buyer_App_First_Build.zip` — installable PHP buyer-interface package.

Read `README-INSTALL.txt` inside the ZIP before deployment. It installs under `/public_html/app/` and reuses the existing Yutendala website/database. It does not replace the live website configuration, payment credentials, vendor dashboard, or admin dashboard.

The existing Epla project is preserved on branch `backup-epla-before-yutendala`.
